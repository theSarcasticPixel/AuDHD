# AuDHD

An addon for **WoW Forever** built for players with ADHD, autism or both, and anyone who gets distracted easily.
Free forever: no ads, paywalls or donations.

Install it from [CurseForge](https://www.curseforge.com/projects/1749872), or download the zip from
[Releases](https://github.com/theSarcasticPixel/AuDHD/releases) and put every folder in it into
your game's `Interface/AddOns` folder. All the folders are needed: `AuDHD` is the addon, the others hold its
guides, maps and quest data.

What it does, how to use it, and the credits: [AuDHD/README.md](AuDHD/README.md).
